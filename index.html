ACI Weekly Report Automation

A private, single-user automation utility that consolidates recurring Excel reports into a macro-enabled workbook and saves dated versions to Google Drive.

How it works

  1. With the account owner's authorization, reads relevant Gmail messages and Excel attachments for the N8, SBM, and NVCG report categories.
  2. Combines the report data into a new XLSM workbook, retaining applicable meeting notes from the previous version.
  3. Saves a new version in a Google Drive folder selected by the account owner, without intentionally overwriting historical versions.

Access and availability

This utility is intended for the developer's personal use only. It is not a publicly available application and does not provide public account registration.
